# DEPT 대시보드 데이터 조회

1. 이 연결(dept-dashboard)을 쓰면 먼저 `get_dashboard_guide`를 불러, 지금 쓸 수 있는 도구·데이터 범위·최신 날짜·질문 예시를 받는다. 그 안내대로 도구를 고른다.
2. 읽기 전용이다. 정산 금액은 권한자만 대시보드에서 보며, 이 연결로는 나오지 않는다.
3. 값이 비면 지어내지 말고 "그 기간 값 없음"이라고 말한다. 처음 쓸 때 대시보드 구글 로그인 → [허용]이 필요하다.
